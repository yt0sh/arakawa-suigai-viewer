# 保守・運用ガイド

本書は「日暮里・荒川 水害情報ビューア」の構成、情報取得、検証、公開運用をまとめた保守資料です。プロジェクトの概要と利用者向けの説明は [README](../README.md)、公開版ごとの変更内容は[リリースノート](releases/)に分けています。

## 保守方針

このサイトは、複数の公的機関が提供する水害関連情報への入口を一つにまとめることを目的としています。集約表示は公式発表の代替ではなく、各情報源へ素早く到達するための補助機能として位置づけています。

保守では次の原則を優先します。

- 警報・避難・河川情報では、見栄えよりも取得と判定の正確性を優先する。
- 取得失敗、提供形式の変更、未対応データを「発表なし」「異常なし」に置き換えない。
- 画面上の要約から、根拠となる公式情報へ直接移動できる状態を保つ。
- 外部サービスへの依存と追加パッケージを抑え、構成を追跡しやすくする。
- 表示仕様、取得仕様、リリース履歴をリポジトリ内に記録する。

## システム構成

Node.js 20以上で動作し、GitHub ActionsではNode.js 24を使用します。追加のnpm依存パッケージはありません。

| パス | 役割 |
| --- | --- |
| `public/` | HTML、スタイル、ブラウザー側処理、静的アセット |
| `api/` | Vercel Functionsのエンドポイント |
| `lib/` | 公式データの取得・解析処理 |
| `config/external-links.json` | 外部リンクとデータ取得先の台帳 |
| `scripts/` | 本番ビルド、外部リンク検査 |
| `tests/` | API、解析処理、画面仕様のテスト |
| `.github/workflows/` | 継続的検証、Release作成、外部リンク検査 |
| `vercel.json` | ビルドと配信の設定 |

`dist/` は `public/` から生成される配布物であり、直接編集の対象には含めません。静的ファイルだけを配信するローカルサーバーでは `/api/*` が動作しないため、APIを含む動作確認にはVercel環境を使用します。

Vercelは `npm run build` を実行し、`dist/` と `api/` を配信します。`scripts/build-v08.mjs` のファイル名は互換性のため維持しています。`build-v07.mjs`、`verify-release.mjs`、`check-live.mjs` は旧版の検証記録であり、現行版のリリース判定には使用していません。

## 開発と検証

標準的な検証手順は次のコマンドで構成されています。

```sh
git clone https://github.com/yt0sh/arakawa-suigai-viewer.git
cd arakawa-suigai-viewer
npm test
npm run check
npm run build
```

| コマンド | 検証内容 |
| --- | --- |
| `npm test` | 現行版をビルドし、APIハンドラー、警報解析、画面仕様のテストを実行 |
| `npm run check` | 主要JavaScriptの構文と外部リンク台帳の整合性を検証 |
| `npm run build` | `public/` から `dist/` を生成し、本番用の雨雲表示範囲を適用 |
| `npm run check:links:validate` | 外部リンク台帳の構造、参照元、登録漏れを検証 |
| `npm run check:links` | 台帳に登録された外部URLへ接続し、応答結果を分類 |

`main` へのpushとPull Requestでは、GitHub Actionsの「Verify」がテストと構文検証を実行します。

## 情報源と表示仕様

主な情報源は次のとおりです。

- [気象庁](https://www.jma.go.jp/bosai/): 警報・注意報、指定河川洪水予報、雨雲
- [水文水質データベース](https://www1.river.go.jp/): 河川水位
- [川の防災情報](https://www.river.go.jp/): 観測所情報と河川情報
- [荒川上流河川事務所](https://www.ktr.mlit.go.jp/arajo/index.html)・[荒川下流河川事務所](https://www.ktr.mlit.go.jp/arage/index.html): 河川カメラと荒川の情報
- [東京都水防災総合情報システム](https://www.kasen-suibo.metro.tokyo.lg.jp/): 東京都の河川情報とライブカメラ
- [荒川区防災情報](https://bosai.city.arakawa.tokyo.jp/): 避難情報と避難所開設状況

サイト内の情報は、提供元が発表する内容と取得時刻を可能な範囲で保持します。自動取得の結果と公式ページへのリンクを併置し、要約だけで判断が完結しない構成としています。

### 警報・注意報

荒川区の警報・注意報は、気象庁の `https://www.jma.go.jp/bosai/warning/data/r8/130000.json` を取得し、地域コード `1311800` に該当する発表を抽出します。

- 最上位の配列に含まれるすべての発表を走査する。
- 同時に発表されている警報・注意報を省略せず集約する。
- カードの色には、発表中の情報で最も高い相当レベルを使用する。
- 取得失敗、形式変更、未対応コードは、取得不能または未対応として表示する。
- 解析仕様の変更には `tests/jma-warning.test.mjs` の更新を伴う。

警報カードは発表状況の要約であり、詳細情報の確認先は気象庁の公式ページです。

### 河川水位

国土交通省「水文水質データベース」の10分水位を取得します。表示期間は12時間と5日間の切り替え式で、初期表示は5日間です。描画できる期間は取得元に観測値が存在する範囲に限られます。

| 観測所 | 観測所ID | グラフの固定縦軸 | カメラ提供元 |
| --- | --- | --- | --- |
| 熊谷 | `303041283308030` | 0〜6 m | 荒川上流河川事務所 |
| 治水橋 | `303041283308060` | 0〜14 m | 荒川上流河川事務所 |
| 岩淵水門（上）※画面表記は「岩淵水門」 | `303041283309040` | 0〜8 m | 荒川下流河川事務所 |

水位グラフの背景色は、平常＝青、水防団待機＝緑、氾濫注意＝黄、避難判断＝赤、氾濫危険＝紫の淡色です。基準水位は観測所ごとに設定しています。単一観測所の水位から避難情報を生成する機能はありません。

## 外部リンクの管理

外部リンクとデータ取得先は `config/external-links.json` に集約しています。各URLには表示名、分類、提供元、重要度、参照元ファイル、検査方針を付与しています。

GitHub Actionsの「External links」は、次の条件で台帳のURLを検査します。

- 関連するソースまたは台帳の更新
- 毎月1日12:17（日本時間）の定期実行
- `workflow_dispatch` による任意実行

検査結果は、分類・名称・提供元・重要度・HTTP応答を含む表としてActionsの実行サマリーに保存します。Issueや外部通知サービスへの連携は行わず、検査結果をリポジトリ内に集約する運用です。

X、LINE、YouTubeなど自動アクセスが制限される可能性のあるURLには `policy: "advisory"` を設定しています。この区分の接続失敗はリンク切れと断定せず、要目視確認として記録します。画面上に外部リンクが追加された一方で台帳に登録がない場合は、整合性検証が失敗します。

GitHubでは、公開リポジトリに60日間活動がない場合に定期ワークフローが停止することがあります。この制約に備え、`workflow_dispatch` を台風・大雨前の点検および定期実行の再開確認に使用できる構成としています。

## ブランチとリリース

- 公開版のソースは `main` に集約する。
- 変更は短期間の作業ブランチとPull Requestで検証し、取り込み後の作業ブランチは整理する。
- `main` への反映はVercelの本番デプロイを起動する。
- すべてのデプロイをバージョン更新とはせず、公開版として記録する変更をReleaseの対象とする。
- 文言、リンク、表示位置、軽微な不具合修正はパッチ版とする。
- 新しい情報ブロック、データ取得先、機能の追加はマイナー版とする。
- バージョン更新では `package.json`、README内の非表示コメント、`vX.Y.Z` タグ、GitHub Releaseを一致させる。
- バージョン番号は公開画面とREADME本文には表示しない。

`package.json` のバージョンが更新されて `main` に反映されると、GitHub Actionsの「Release」が同名のタグとReleaseを作成します。`docs/releases/vX.Y.Z.md` が存在する場合は、その内容をRelease本文に使用します。

過去の作業ブランチと保管方針は[ブランチ整理記録](branch-archive.md)にまとめています。

## アクセス解析

本番サイトの利用状況はGA4（測定ID `G-T0QZT180EM`）で計測します。読み込み処理は `public/analytics.js` に置き、対象ホストを `arakawa-suigai-viewer.vercel.app` に限定しています。localhostとVercelのプレビュー環境は計測対象外です。

Googleシグナルと広告パーソナライズのシグナルは無効です。計測に関する案内とGoogleのデータ利用ポリシーへのリンクは公開画面のフッターに掲載しています。
