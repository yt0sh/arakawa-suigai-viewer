# 日暮里・荒川 水害情報ビューア

<!-- release-version: **v0.9.0** -->

日暮里・荒川区周辺の水害情報を提供元をまたいで集約しました。気象庁・国土交通省・東京都・荒川区など、公式情報へのリンクをまとめています。

**[公開サイトを開く](https://arakawa-suigai-viewer.vercel.app/)**

## 主な機能

| 分類 | 内容 |
| --- | --- |
| 警報・避難情報 | 荒川区の警報・注意報、荒川の氾濫情報、避難情報を表示し、各公式ページへ案内します |
| 荒川の水位 | 熊谷・治水橋・岩淵水門の現在水位、10分・1時間の変化、水位推移、基準水位を確認できます |
| 河川カメラ | 熊谷・治水橋・岩淵水門の河川カメラに加え、笹目橋・浮間橋・小台のライブ映像を掲載しています |
| 天気・雨雲 | 気象庁の雨雲を地図に重ねて表示し、荒川区の天気、雨雲の動き、洪水キキクルへ案内します |
| 避難・ハザード | 避難場所・避難所、水害時の避難先、荒川区防災地図へのリンクをまとめています |
| 交通・ライフライン | JR東日本・東京メトロ・京成電鉄・都営地下鉄と、電気・ガス・水道・下水道の公式情報へ案内します |
| SNS・情報交換 | 防災関係機関のX、地域名を含む投稿、住民向けLINEオープンチャットを掲載しています |
| 防災アプリ | 東京都・荒川区・NHK・Yahoo!・NERVの防災アプリをまとめています |

## 利用上の注意

このサイトは公式情報の再表示・集約を目的とした補助サイトです。取得元の更新遅延、通信障害、カメラ配信の停止などが起こり得ます。画面の観測時刻・取得状態を確認し、最新情報は各リンク先で確認してください。

## 作成の経緯

2019年10月、[令和元年東日本台風（台風第19号）](https://ja.wikipedia.org/wiki/%E4%BB%A4%E5%92%8C%E5%85%83%E5%B9%B4%E6%9D%B1%E6%97%A5%E6%9C%AC%E5%8F%B0%E9%A2%A8)の接近時に荒川氾濫に危機感を覚えてLINEオープンチャットと一緒に作りました。それから[2021年8月の大雨](https://ja.wikipedia.org/wiki/%E4%BB%A4%E5%92%8C3%E5%B9%B48%E6%9C%88%E3%81%AE%E5%A4%A7%E9%9B%A8)の際に少し更新しています。どちらもWikipediaのページがあるほどの災害だったのだなと思いを馳せます。

2026年9月の台風接近時には、ChatGPTのGPT-5.6 Sol・GPT-6 Astraに要件や改善指示を与え、出力を確認しながら大幅に刷新しました。
