# 日暮里・荒川 水害情報ビューア

<!-- release-version: **v0.9.0** -->

日暮里・荒川区周辺の水害関連情報を一画面に集約したビューアです。気象庁・国土交通省・東京都・荒川区などが発表する最新情報へ、すぐにアクセスできます。

**[公開サイトを開く](https://arakawa-suigai-viewer.vercel.app/)**

## 主な機能

| 分類 | 掲載内容 |
| --- | --- |
| 警報・避難 | 荒川区の警報・注意報、荒川の氾濫情報、避難情報 |
| 河川 | 熊谷・治水橋・岩淵水門の水位推移、河川カメラ |
| 天気 | 荒川区周辺の雨雲、天気、洪水キキクル |
| 避難・生活 | 避難所、ハザードマップ、交通・ライフライン情報 |
| 地域の情報 | 防災関係機関のX、地域名を含む投稿、LINEオープンチャット、防災アプリ |

交通・ライフラインやSNSの投稿は、各機関・サービスの最新情報へ移動できる構成です。

## 作成の経緯

このサイトの原型は、2019年10月の[令和元年東日本台風（台風第19号）](https://ja.wikipedia.org/wiki/%E4%BB%A4%E5%92%8C%E5%85%83%E5%B9%B4%E6%9D%B1%E6%97%A5%E6%9C%AC%E5%8F%B0%E9%A2%A8)接近時に作りました。当時はマンションの1階に住んでおり、荒川の増水や浸水が自宅に直結する切迫した問題でした。

必要な公的情報をすぐ参照できるようGoogle Sitesにまとめ、地域の状況を共有するLINEオープンチャットも開設しました。案内を印刷してマンション内で配布したのが、この取り組みの始まりです。

[2021年8月の大雨](https://ja.wikipedia.org/wiki/%E4%BB%A4%E5%92%8C3%E5%B9%B48%E6%9C%88%E3%81%AE%E5%A4%A7%E9%9B%A8)に合わせて情報を更新。2026年9月には掲載情報を大幅に追加し、画面構成を全面的に見直しました。Google SitesからVercelへ移行し、「日暮里・荒川 水害情報ビューア」として再構成しています。

2026年9月の再構築は、ChatGPTのGPT-5.6 Sol・GPT-6 Astraに要件や改善指示を与え、出力の確認と採否判断を重ねながら進めました。

大雨の際にすぐ使えるよう、その都度必要な情報と導線を見直しています。地域に必要な情報へ辿り着きやすくするという考え方は、開設時から変わっていません。

## 水位グラフとデータ源

国土交通省「水文水質データベース」の10分水位を取得します。表示期間は **12時間／5日間** で切り替え、初期表示は **5日間** です。実際に描画できる範囲は取得元の観測データによります。

| 観測所 | 観測所ID | グラフの固定縦軸 | カメラ提供元 |
| --- | --- | --- | --- |
| 熊谷 | `303041283308030` | 0〜6 m | 荒川上流河川事務所 |
| 治水橋 | `303041283308060` | 0〜14 m | 荒川上流河川事務所 |
| 岩淵水門（上）※画面表記は「岩淵水門」 | `303041283309040` | 0〜8 m | 荒川下流河川事務所 |

背景色は、平常＝青、水防団待機＝緑、氾濫注意＝黄、避難判断＝赤、氾濫危険＝紫の淡色です。基準水位は観測所ごとに設定しています。単一観測所の水位から避難指示を自動生成するものではありません。

主な情報源:

- [気象庁](https://www.jma.go.jp/bosai/): 警報・注意報、洪水予報、雨雲
- [水文水質データベース](https://www1.river.go.jp/): 水位観測値
- [川の防災情報](https://www.river.go.jp/): 河川情報の原典確認
- [荒川上流河川事務所](https://www.ktr.mlit.go.jp/arajo/index.html)・[荒川下流河川事務所](https://www.ktr.mlit.go.jp/arage/index.html): 河川カメラ・河川情報
- [東京都水防災総合情報システム](https://www.kasen-suibo.metro.tokyo.lg.jp/): 東京都の河川・カメラ情報
- [荒川区防災情報](https://bosai.city.arakawa.tokyo.jp/): 避難情報・避難所開設状況

## 利用上の注意

このサイトは公式情報の再表示・集約を目的とした補助サイトです。取得元の更新遅延、通信障害、カメラ配信の停止などが起こり得ます。画面の観測時刻・取得状態を確認し、最新情報は各リンク先で確認してください。
